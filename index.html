WHAT IS THE TERRALEAK?

Steam2 TerraLeak — a 12–13 TB “as-complete-as-possible content server dump” of Valve's defunct Steam2 infrastructure (Sep 2003 → Feb 2013) circulating via BitTorrent since Aug 29, 2026.

It holds every version of every game uploaded to old Steam2 servers: public builds plus pre-release, prototype & playtest depots from Valve and third-party publishers. File names look like [depot_id]_[version]_[crc]_[hash] — DATs + blobs.

HOW THE LEAK HAPPENED
  1. 2003–2013: games packaged in proprietary Steam2 format.
  2. Mar 2013: Valve moves to SteamPipe (HTTP file trees). Old servers left reachable.
  3. Pre-2026: hoarders quietly pull depots via open endpoint.
  4. Aug 29 2026: someone bundles ~12 TB + torrent + readme. VCC Discord confirms upload log.
  5. Now: GitHub catalogs, steam2-db.pages.dev, HiddenPalace pages. Valve silent.

    FORENSICS — WHAT WE VERIFIED WHILE SCRAPING

    1. Size claims

    12 TB is the consensus (Ars, TechSpot, IGN, Verge, Engadget). Tom's Hardware / TechPowerUp note 12–13 TB once dupes counted. Uploader screenshot showed a 22 TB server log (likely raw + staging). We display 12 TB as canonical.

    2. “Hack” vs endpoint

    Gabe Follower + Scolcer + Ars all agree: public endpoint, no auth. Whether pulled recently or hoarded pre-2013 and bundled now is still disputed (VCC mods lean “old private collection, now public”).

    3. What's NOT in it

    Nothing post-Feb 2013. No playable HL3 / Ep3. Only Weaponizer model (already seen in Valve's Ep3 documentary) + “ep3” strings. No post-2013 ValveTestApp depots — many destroyed/renamed.

    4. Third-party blast radius

    Because Steam2 stored every publisher's uploads, leak includes Spore, Dragon Age: Origins, Arkham Asylum, GTA3-era builds, Mafia II, Civ V, Sonic 4, Saw (PC builds never released). That's why lawyers care more than gamers.

    5. Scrape method for this site

    Live web search (Aug 29 → Oct 11 2026 press) + fetch of Ars Technica canonical + fetch of HiddenPalace Steam2_Content_Server category (≈132 rows parsed) + steam2-db probe. Normalized into tracker.js DB below. Re-scrape button re-runs local triage calc + timestamp.
